Nouvelle Structure des Données

Cyberware, Pouvoirs et Sorts gérés par référence

✓ Structure Unifiée

Les cyberwares, pouvoirs et sorts sont maintenant gérés de manière similaire :

  • Chaque élément a un id unique
  • Les données complètes sont stockées dans des fichiers YAML séparés
  • Les fichiers de personnages référencent simplement les IDs
  • Les templates utilisent site.data pour récupérer les données
Fichiers Créés
Cyberware
  • _data/cyberware_list.yaml
  • 11 cyberwares définis
  • Chaque cyberware a : id, name, type, essence, capacity, etc.
Pouvoirs
  • _data/powers_list.yaml
  • 10 pouvoirs définis
  • Chaque pouvoir a : id, name, category, type, magic_cost, etc.
Modifications des Fichiers de Personnages
Ancienne Structure (Pouvoirs) :
powers:
- name: Improved Reflex
rating: 1
magic: 1.5
description: "..."
Nouvelle Structure (Pouvoirs) :
powers:
- id: improved_reflexes
rating: 1
Avantages de la Nouvelle Structure
  • Cohérence : Tous les éléments (cyberware, pouvoirs, sorts) utilisent le même modèle
  • Maintenabilité : Les données sont centralisées et faciles à mettre à jour
  • Réutilisabilité : Plusieurs personnages peuvent référencer les mêmes éléments
  • Extensibilité : Facile d'ajouter de nouveaux éléments sans modifier les templates
  • Performance : Moins de duplication de données
